# Project Overview

Financial data analysis is an important component of investment research, corporate performance evaluation, and economic decision-making. Historical stock prices and company revenue provide useful information for understanding market behavior and evaluating business performance. However, manually collecting financial information from web pages can be time-consuming and inefficient, particularly when data must be retrieved from multiple sources or organized for further analysis.

Web scraping provides an automated approach to collecting information from web pages. By using programming libraries to retrieve and parse HTML documents, researchers can extract relevant information and transform it into structured datasets suitable for statistical analysis and visualization.

This project, titled Extracting Stock Data Using Web Scraping, applies Python programming techniques to retrieve and process stock-related information from designated Amazon and Netflix HTML webpages provided as part of the IBM Developer Skills Network project. The project emphasizes webpage retrieval, HTML parsing, data extraction, and the preparation of financial data for analysis.

# Conclusion

This project demonstrates the application of Python-based web scraping techniques to the collection and preparation of financial data. The combination of the requests, BeautifulSoup, and pandas libraries provides a systematic method for retrieving HTML documents, extracting relevant tables, and organizing the resulting information for further analysis.

The methodology illustrates the role of automated data collection in financial research and provides a practical introduction to data cleaning and visualization. Although the approach is useful for educational and exploratory purposes, its effectiveness depends on source reliability, webpage stability, and appropriate validation of the extracted information.

In conclusion, the project provides a foundation for more advanced work in financial data analytics, automated reporting, and comparative stock market research.
